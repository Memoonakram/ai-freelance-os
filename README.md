#  AI-Powered Freelance Workflow Automator

An end-to-end intelligent automation system designed for high-ticket AI freelancers and agencies. This application takes client requirements, generates structured project scopes and milestone breakdowns using Gemini AI, and seamlessly pushes them directly into **ClickUp** as managed workflows.

---

##  Tech Stack & Architecture

* **Frontend:** Streamlit
* **AI Engine:** Google Gemini API (`google-genai`)
* **Project Management Integration:** ClickUp REST API
* **Backend Runtime:** Python 3.10+

---

##  Key Features

* **Automated Proposal & Scope Generation:** Transforms raw client briefs into structured execution proposals.
* **Milestone Breakdown Engine:** Automatically extracts step-by-step deliverable milestones.
* **1-Click ClickUp Push:** Creates task cards with descriptions, budgets, and nested subtasks directly in your workspace list.
* **Production-Ready Error Handling:** Built-in dynamic status resolution for seamless API communication.
